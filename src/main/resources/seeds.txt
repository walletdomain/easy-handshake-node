# Handshake bootstrap seed nodes for this project.
#
# Loaded from the classpath by SeedDatabase (see its own class comment)
# on every startup -- not just a first-ever run. Any line below whose IP
# isn't already known to a node's persistent seed database, and hasn't
# been explicitly tombstoned ("deleted:<ip>") by that node, gets merged
# in as a builtin seed. Already-known IPs are left untouched (whatever
# PeerScorecard/SeedDatabase has learned about them stays), and nothing
# is ever removed from an existing install just because a line is
# removed here -- removal happens only through the normal scoring/
# tombstone mechanism, never by editing this file.
#
# Format (pipe-delimited, one seed per line):
#   brontideKey|ip|port|label
#
# - brontideKey: base32-encoded compressed secp256k1 public key (33 bytes).
#   Required -- this project is Brontide-only (see SeedDatabase's class
#   comment for why).
# - ip: IPv4 or IPv6 address.
# - port: almost always 44806 (the standard Brontide P2P port).
# - label: free-form human-readable name, used only for logging.
#
# Lines starting with # and blank lines are ignored.
#
# Seed list verified on 2026-10-18 (TCP connect from two machines plus a live Brontide handshake and VERSION
# exchange from the node). Only entries that completed a real Brontide handshake are active.
#
# A node never adds itself to its own peer table: a line whose key is this node's own key (or whose IP
# is this node's confirmed public IP) is skipped at load, so the same list can ship in every install.
